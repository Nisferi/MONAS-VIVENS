# 06 — Таблички Судеб (Future Protocols)

> Реализуется в модуле `src/tablets/`.
> Связанные блоки: [05-future](05-future.md), [07-run-loop](07-run-loop.md).

Игрок собирает правила из готовых блоков (дропдауны, не текст):

```
ЕСЛИ [условие] ТО [действие]
```

## Набор MVP — 3 условия × 3 действия

| Условия | Действия |
|---|---|
| Φ упадёт ниже X | разорвать заражённую связь |
| энергия поля ниже Y% | перевести кластер в спячку |
| Хаос выше Z% | пожертвовать кластер (отрезать) |

## Свойства

- Табличка высекается **заранее** и спит, пока условие не наступит.
- Когда предсказанный кризис приходит — табличка срабатывает сама, без игрока.
- **Цена:** высечение таблички стоит ресурса сейчас (жертвуешь ростом ради будущего).
  Это центральный выбор игры: жить настоящим или строить будущее.

## Архитектурный контракт

`tablets/engine.ts` — **единственный** модуль, который меняет состояние «извне» правил,
и только по сработавшему условию.
