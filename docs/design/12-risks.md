# 12 — Риски и лекарства

| Риск | Лекарство |
|---|---|
| Spore-ловушка: разрастание в «три игры» | одна валюта Φ, один глагол «связывать», морозилка фич; не трогать морозилку до релиза MVP |
| Прогноз ощущается угадайкой | строгий детерминизм: будущее = fast-forward того же движка; никакого скрытого RNG после старта |
| Эмерджентность не рождает «интересную» жизнь на 64×64 | шаг 1 плана — именно проверка этого; крутить правила до «вау» прежде, чем строить остальное |
| Φ-формула балансно ломается (доминирует один член) | нормировка каждого члена в [0..1] + логарифм по размеру кластеров; балансные тесты на шаге 3 |
| Философия остаётся текстом, а не опытом | каждая идея обязана иметь механику: дилемма = тяги уровней, Абсолют = Φ, судьба = детерминизм. Если у идеи нет механики — она не входит |
| Один разработчик выгорает | каждый шаг плана играбелен; продукт существует с шага 1 |
