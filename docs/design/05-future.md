# 05 — Детерминированное будущее

> Реализуется в модуле `src/future/`.
> Связанные блоки: [04-lenses](04-lenses.md), [06-tablets](06-tablets.md), [09-architecture](09-architecture.md).

Принцип Конвея: мир полностью предопределён правилами, но непредсказуем без расчёта.
Предвидение — это не угадайка, а вычисление.

## Реализация

Прогноз = тот же движок симуляции, прогнанный вперёд в фоне.

- Реальное время: симуляция идёт на 1×.
- Прогноз: копия состояния поля прогоняется на N тиков вперёд без отрисовки;
  игроку показывается, что случится, если он ничего не изменит.
- **Сила разума = дальность зрения:** N растёт с Φ. Низкое Φ — туман уже через
  10 тиков. Высокое — ясность на 200 тиков вперёд.

Философская честность: судьба не случайна — она лишь трудна для расчёта.
Разум и есть то, что её рассчитывает.

## Технические требования

- Прогноз гоняет **тот же** чистый `tick(state, rules)` из `core` — отдельного кода
  будущего не существует (защита от риска «прогноз ощущается угадайкой»).
- Никакого скрытого RNG после старта партии: весь рандом — из seed при старте.
- Прогноз выполняется в Web Worker, чтобы не подвешивать UI на слабых телефонах.
- Угроза партии детерминирована и заложена в seed (`future/threat.ts`).
