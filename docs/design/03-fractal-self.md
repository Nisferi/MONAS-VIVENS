# 03 — Fractal Self: конфликт желаний уровней

> Механическое тело главной дилеммы: «Можно ли стать единым, не уничтожив отдельное?»
> Связанные блоки: [02-phi](02-phi.md), [04-lenses](04-lenses.md), [08-endings](08-endings.md).

Каждый устойчивый кластер имеет уровень организации и «тягу». Тяги противоречат друг
другу — игрок не может удовлетворить всех:

| Уровень | Желание | Куда тянет систему |
|---|---|---|
| Семя (клетка) | делиться | рост + Хаос, износ формы |
| Форма (организм) | сохранять себя | стабильность, торможение роста |
| Рой (сеть форм) | сливаться | Unity ↑, свобода частей ↓, риск Сфайроса |

Усилишь связи ради Φ — задушишь деление, система застынет. Дашь свободу — Φ рассыплется
в Хаос. Балансирование этих тяг руками — и есть переживание главной дилеммы.

## Принцип «философия = механика»

Каждая идея обязана иметь механику:

| Идея | Механика |
|---|---|
| Дилемма единого/отдельного | противоречащие тяги уровней |
| Абсолют | число Φ |
| Судьба | детерминизм движка |
| Предвидение | fast-forward того же `tick()` |

Если у идеи нет механики — она не входит в игру.
