# 01 — Словарь и космология

> Трёхъярусный канон имён и полный словарь терминов.
> Связанные блоки: [00-concept](00-concept.md), [02-phi](02-phi.md), [11-aesthetics](11-aesthetics.md).

## Трёхъярусный канон имён

Исторически честная структура — так знание текло через древний мир:

| Слой | Язык | Термины |
|---|---|---|
| Имя мира | латынь (алхимия) | MONAS VIVENS |
| Физика мира | греческий (досократики) | Семена, Филия, Нейкос, Хаос, Мнемозина, Сфайрос |
| Руки игрока | шумерский (бронзовый век) | Ме, Таблички Судеб, Глиняная летопись |

## Полный словарь терминов

| Термин | Источник | В механике |
|---|---|---|
| **Монада** | Пифагор, Лейбниц | единица жизни, зеркало целого; каждый уровень — монада своего масштаба |
| **Семена** (Spermata) | Анаксагор | живые клетки на поле; частицы, несущие потенциал целого |
| **Филия** (Любовь) | Эмпедокл | связи между клетками и узлами; сила соединения |
| **Нейкос** (Вражда) | Эмпедокл | напряжение, разрывающее связи; штраф к Φ, но обязан быть > 0 |
| **Хаос** | Гесиод | шум: одиночные мерцающие клетки без формы и памяти |
| **Мнемозина** | греч. мифология | память: возраст стабильности кластеров |
| **Сфайрос** | Эмпедокл | концовка тотального слияния — Ложный Абсолют |
| **Ме** | Шумер | божественные законы; ползунки правил, которые крутит игрок |
| **Таблички Судеб** (Дуп Шимати) | Шумер | Future Protocols: правила ЕСЛИ→ТО, заложенные до кризиса |
| **Глиняная летопись** | Шумер | итоговый текст партии |
| **Φ (фи)** | Тонони (IIT) | единственная валюта игры: мера интегрированности = сознания |
