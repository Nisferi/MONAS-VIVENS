# План игры MONAS VIVENS: сделано и впереди

Обновлено: 2026-06-10. Живая сборка: https://nisferi.github.io/MONAS-VIVENS/

## Что это за игра

Философская artificial-life стратегия: игрок — закон, а не рука. Он настраивает
Ме (правила мира), сеет Семена, высекает Таблички Судеб и проводит мир от
слепой клетки до разума, видящего собственное будущее. Сердце игры — честный
детерминизм: будущее считается тем же движком, что и настоящее, поэтому
прогноз, реплеи, дуэли и вечный мир-тамагочи — не фокусы, а следствия одного
закона. Канон — docs/design/01..14.

## ЧАСТЬ I. Сделано

### Ядро симуляции (core/)
- [x] Поле 48/64/96 на торе, типы клеток: Пусто, Семя, Сигнал, Прах, Спора
- [x] Правила Конвея с настраиваемым Ме (рождение/выживание/Прах/Воля)
- [x] Энергия поля: приток, расход, голод (ужесточение выживания)
- [x] Рельеф из seed: Кристаллы (вечные стены) и Родники (приток энергии)
- [x] Детерминизм всего: mulberry32 от seed, ни одного Math.random в ядре
- [x] Оптимизация: таблицы заворота тора, ~20 000 тиков/сек

### Сознание мира (phi/)
- [x] Кластеры с идентичностью между тиками (Мнемозина имеет смысл)
- [x] Формула Φ = ∛(Семена×Филия×Мнемозина) − Хаос − Нейкос, все члены [0..1]
- [x] Балансные тесты: Φ дышит 9–40, ни один член не доминирует
- [x] Кодекс форм: распознавание 10 канонических существ (глайдер и др.)
  инвариантно к фазе/повороту/отражению

### Умная жизнь (лестница познания, привязана к Φ)
- [x] Ярус 1 — Химия: сигнальное поле-«грибница» (эмиссия, диффузия,
  затухание), тропизм рождений к сильному сигналу
- [x] Ярус 2 — Кворум: зрелые формы в стрессе сами уходят в Споры перед
  штормом (проактивная спячка)
- [x] Ярус 3 — Эволюция: геном осторожности, наследование доминирующей
  линией, мутация hash(позиция, тик), отбор штормами; подтверждённая
  дивергенция (штормовой биом 130→189, спокойный 125→85)
- [x] Ярус 4 — Воля: ползунок Ме 0..10 (автономия форм), дальность их
  предчувствия растёт с волей; концовка «Тиран Будущего»

### Будущее (future/)
- [x] Прогноз тем же tick() в Web Worker, 8 кадров пути
- [x] Горизонт взора N = f(Φ), скраббер времени, веер будущих
  (лиловая тень старого закона при правке Ме)
- [x] Судьба из seed: серия из 3 Нейкос-штормов нарастающей силы

### Таблички Судеб (tablets/)
- [x] ЕСЛИ (Φ/энергия/Хаос/шторм ближе N) → ТО (отсечь край, спячка,
  жертва, влить энергию, засеять кольцо), до 5 штук, цена 12 энергии
- [x] Срабатывают сами, один раз, журналируются в летопись

### Петля партии (run/)
- [x] Фазы: Genesis → Морфогенез → Разум → Шторм↔Передышка ×3 → Развязка
  (~11–12 мин на ×1; скорость ½/1/2/4)
- [x] 6 концовок из состояния: Сфайрос, Пророк Без Рук, Слепое Болото,
  Мудрая Грибница, Абсолют Через Различие, Тиран Будущего
- [x] Счёт с принципом элегантности, Глиняная летопись, эхо мира
  (новый всходит на прахе прежнего)
- [x] 3 биома × 3 архетипа, Мир недели, 5 Испытаний Сеятеля со звёздами,
  «Расклад» (фигуры + ставка Долгожитие/Расцвет, расклад дня)

### Режимы
- [x] Поток (мир из бульона), Сеятель (горсть Семян руками)
- [x] Очаг — тамагочи: мир живёт в реальном времени, автосейв, честная
  домотка отсутствия (кап — неделя), вечные штормы
- [x] Дыхание — самопознание: 10 минут, темп 4-4-8, руки убраны,
  строка рефлексии
- [x] Реплеи (код в сотни байт, бит-в-бит) и Дуэли (счёт+реплей-
  доказательство, идентичные миры, шеринг в Telegram)

### Лицо игры (ui/, lens/)
- [x] 5 линз: Семена, Филия (граф), Разум (будущее), Хроника (память
  места), Мицелий (химия)
- [x] 3 темы: Глина и Золото, Папирус, Обсидиан и Лёд
- [x] Главное меню, кнопка ☰, настройка мира отдельным экраном
- [x] Прицельный посев: прицел над пальцем, перекрестье, стрелки ◀▲▼▶,
  кнопка «Посадить»; автозум и сетка в фазе посева
- [x] Панель-Скрижаль (вкладки Ме/Таблички/Журнал) по кнопке; поле
  вписывается над открытой панелью
- [x] Спарклайн Φ, цитаты древних (26, по фазам), звук Web Audio
  (гул поля, колокола, рокот шторма), сцены концовок, дыхание поля
  между тиками, PNG-летопись
- [x] Роды клеток (3 культуры с наследованием), оттенки по возрасту

### Платформа и качество
- [x] GitHub Pages деплой, PWA (офлайн), Telegram Mini App + CloudStorage
- [x] Golden-реплеи в CI: детерминизм защищён тестом на каждом коммите
- [x] Мобильная адаптация: safe-area, dirty-рендер, жесты

## ЧАСТЬ II. Впереди

### Стратегическая глубина (§15–16)
- [x] Дыхание Творца: единая валюта вмешательства, копится от Φ
  (0.02 + 0.004·Φ за тик), тратится: посев 2, правка Ме 8, Табличка 12
- [x] Обеты: Абсолют / Сфайрос / Грибница — ×2 за исполнение, ×0.6 за нарушение
- [x] Живая клетка целиком (§16): АТФ, мембрана, язык, симбиоз, политика
- [x] Пожиратели: хищники приходят волнами (тик 700, далее каждые 800),
  охотятся по запаху грибницы, переваривают 4 тика, плодятся от сытости,
  гибнут без еды за 30 тиков — популяция жертв падает с ~265 до ~55–80,
  но не вымирает
- [ ] Провинции и локальные законы Ме
- [ ] Демиург-соперник «Спор Богов»

### Ближний круг (быстрые победы)

- [ ] Новые условия/действия Табличек («род вымирает», смягчение правил

- [ ] Локализация EN (тексты уже изолированы)

## Принципы, которые не меняются
1. Детерминизм неприкосновенен (golden-тест — страж).
2. Игра остаётся статическим сайтом; серверы — только опциональные надстройки.
3. Концовки следуют из состояния системы, не из скрипта.
4. Никакого pay-to-win; монетизация, если будет, — только косметика.
5. Игрок — закон, а не рука: каждая новая механика усиливает это, а не размывает.
