# 02 — Формула Φ: сердце игры

> Единственная валюта игры. Реализуется в модуле `src/phi/`.
> Связанные блоки: [03-fractal-self](03-fractal-self.md), [09-architecture](09-architecture.md), [12-risks](12-risks.md).

## Формула

```
Φ = Семена × Филия × Мнемозина − Хаос − Нейкос
```

## Расшифровка членов

- **Семена** — количество живых клеток в устойчивых кластерах.
- **Филия** — средняя внутренняя связность кластеров (рёбра между соседями).
- **Мнемозина** — возраст стабильности (сколько тиков кластер сохраняет себя).
- **Хаос** — число одиночных клеток, живущих меньше порога T тиков.
- **Нейкос** — накопленное напряжение (разрывы, перегрузка, конфликты желаний).

## Смысловые предостережения (баланс)

- Много Семян без Филии — биомасса, не разум.
- Много Филии без Мнемозины — реактивный рой.
- Много Мнемозины без свободы — догма.
- **Нейкос = 0 — принудительный Сфайрос.** Щепотка Вражды обязательна,
  иначе целое умирает в единстве.

## Балансные требования к реализации

(из раздела рисков — обязательны на шаге 3 плана сборки)

- Нормировка каждого члена в `[0..1]`.
- Логарифм по размеру кластеров (чтобы один гигантский кластер не доминировал).
- Балансные тесты: ни один член не должен доминировать в типовой партии.
- `phi/*` — только чтение состояния; модуль возвращает число и разбивку по членам,
  ничего не пишет.

## Калибровка (итерация 1, по балансному тесту шага 3)

Тест: 600 тиков Конвея, плотность 0.18, три seed. Находки и решения:

- **Произведение трёх дробей структурно мельче линейных штрафов** → берём
  кубический корень из произведения (смысл сохранён: ноль любого члена
  обнуляет целое), затем вычитаем взвешенные Хаос и Нейкос (×0.25).
- **Нейкос считает только события форм** (кластеры ≥ 3 клеток): гибель
  мерцающего шума — забота Хаоса, иначе шум штрафует Φ дважды.
- Константы Нейкоса: нагрев 0.008/смерть, 0.005/раскол, остывание ×0.95 за тик;
  стационар ≈ нагрев / (1 − остывание).
- Итоговые диапазоны в живом Конвее: Φ ≈ 9–40, члены в середине шкалы,
  ни один не прибит к 0 или 1. Пустой мир: Φ = 0.

## Открытые вопросы для итераций

- Точное значение порога T (Хаос) — подбирается на шаге 3.
- Как Нейкос накапливается и затухает — кандидаты: разрыв связей, плотностная
  перегрузка, конфликт тяг уровней (см. [03-fractal-self](03-fractal-self.md)).
