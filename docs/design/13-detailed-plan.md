## I. Геймплей одной партии по минутам (целевой опыт, 10–20 мин)

| Время | Фаза | Что происходит | Что делает игрок |
|---|---|---|---|
| 0:00–0:30 | Старт | экран выбора: 3 биома × 3 архетипа, seed | выбирает старт (9 комбинаций) |
| 0:30–4:00 | **GENESIS** (линза 1) | поле оживает; Хаос мерцает, формы рождаются и гибнут | крутит Ме до появления устойчивых кластеров |
| ~4:00 | Веха | первый кластер прожил ≥ T тиков → **открывается линза 2** | переключается на линзу Филии |
| 4:00–8:00 | **МОРФОГЕНЕЗ** (линза 2) | кластеры свёрнуты в узлы; видны связи | укрепляет/режет связи, растит Φ |
| ~8:00 | Веха | Φ достигла порога разума → **открывается линза 3** и горизонт прогноза | впервые видит будущее |
| 8:00–10:00 | **УГРОЗА** | прогноз показывает детерминированный кризис через N тиков (в тумане) | оценивает: хватит ли дальности зрения |
| 10:00–14:00 | **РАЗУМ** (линза 3) | система растёт; кризис приближается | высекает Таблички Судеб, платя ресурсом сейчас |
| ~14:00–16:00 | **КРИЗИС** | таблички срабатывают сами (или их не было) | наблюдает, как его прошлые решения спасают (или нет) |
| 16:00–18:00 | Развязка | система переживает кризис или рушится; финальное Φ | дотягивает баланс Нейкоса/Хаоса до желанной концовки |
| 18:00–20:00 | **ФИНАЛ** | концовка + Φ-счёт + Глиняная летопись | читает летопись, делится seed, начинает заново |

Ключевое переживание: **в кризис игрок ничего не нажимает** — он смотрит, как
работают (или отсутствуют) его прошлые решения. Это и есть «закон, а не рука».

### Шаг 2 — Панель Ме ✅ (собрано)

|---|---|

### Шаг 3 — Φ и линза 2 (следующий)

| Подзадача | Критерий |
|---|---|
| `phi/clusters.ts`: connected components по живым клеткам, отслеживание идентичности кластера между тиками | кластеры стабильно нумеруются, не «прыгают» |
| `phi/mnemosyne.ts`: возраст стабильности кластера | возраст растёт, сбрасывается при распаде |
| `phi/philia.ts`: внутренняя связность кластеров (рёбра/клетки) | плотный кластер > рыхлого |
| `phi/chaos.ts`: одиночки, живущие < T тиков | мерцание поднимает Хаос |
| `phi/neikos.ts`: напряжение (распады, перегрузка плотности); правило Нейкос > 0 | Нейкос виден и не равен нулю в живой системе |
| `phi/phi.ts`: формула с нормировкой членов в [0..1] + log по размеру | ни один член не доминирует (балансный тест) |
| `lens/lens2.ts`: свёртка кластеров в узлы, рендер графа золотыми нитями | узлы и связи читаются глазом |
| `lens/switcher.ts`: условие открытия линзы 2 (кластер прожил ≥ T) | линза открывается событием, с текстом канона |
| HUD: число Φ + разбивка по членам | видно, **почему** Φ такая |

**Критерий приёмки шага:** видно, как связи дают число; линза переключается.

### Шаг 4 — Детерминированное будущее

| Подзадача | Критерий |
|---|---|
| `future/forecast.ts`: fast-forward копии мира тем же `tick()` в Web Worker | прогноз не подвешивает UI |
| `future/horizon.ts`: N = f(Φ), туман за горизонтом | дальность растёт с Φ (10 → 200 тиков) |
| `lens/lens3.ts`: рендер целого + Φ + горизонт | будущее видно как полупрозрачный слой/шкала |
| Кэш и инвалидация прогноза при смене Ме | прогноз честен после любого вмешательства |

**Критерий приёмки шага:** видишь будущее; дальность растёт с Φ; прогноз
совпадает с тем, что реально наступает (детерминизм проверяем тестом).

### Шаг 5 — Таблички Судеб

| Подзадача | Критерий |
|---|---|
| `tablets/conditions.ts`: Φ < X, энергия < Y%, Хаос > Z% | условия считаются из состояния |
| `tablets/actions.ts`: разорвать связь, спячка кластера, пожертвовать кластер | каждое действие наблюдаемо меняет мир |
| `tablets/engine.ts`: спящие правила, проверка каждый тик, срабатывание | табличка срабатывает сама, ровно один раз |
| `tablets/cost.ts`: цена высечения (ресурс сейчас) | высечение — ощутимая жертва |
| `ui/tabletUI.ts`: дропдауны ЕСЛИ→ТО, список высеченных табличек | сборка правила за ≤ 3 касания |

**Критерий приёмки шага:** заложил решение — оно спасло систему без тебя.

### Шаг 6 — Партия целиком

| Подзадача | Критерий |
|---|---|
| `core/energy.ts`: энергия поля (приток/расход) — топливо угрозы и табличек | энергия читается в HUD |
| `future/threat.ts`: 1 детерминированная угроза из seed | угроза одинакова при одном seed |
| `run/stages.ts`: фазы Genesis → Морфогенез → Разум | переходы по вехам, тексты канона |

## III. Вехи и правила работы

- **M1 (есть):** живое поле + Ме, деплой на Pages — игру можно показать.
- **M2 = шаг 3:** Φ на экране — философия получила число.
- **M3 = шаг 4:** будущее видно — главная фишка работает.
- **M4 = шаг 6:** полная партия — это уже игра.
- **M5 = шаг 7:** MVP-релиз (Web + ТГ + PWA).

Правила:
1. Не начинать шаг N+1, пока шаг N не играется (правило выживания одиночки).
2. Каждая идея обязана иметь механику — иначе не входит ([03-fractal-self](03-fractal-self.md)).
3. Морозилку (сны, память, мультиплеер, доска) не трогать до релиза MVP.
4. Балансные тесты Φ — обязательная часть шага 3, не «потом».

## IV. Пост-MVP (морозилка, по приоритету)

1. **Weekly Seed + лидерборд** — асинхронный мультиплеер на готовом детерминизме.
2. Остальные 2 концовки (Тиран Будущего, Абсолют Через Различие) и тонкий баланс.
3. Ghost Worlds / Fossil Archive — обмен мирами через seed + летопись.
4. `dreams/` — сон разума, пророческие сны.
5. `memory/` — травма, память vs забывание.
6. `board/` — нарративная рамка «знаков эпох».
7. Capacitor (Android/iOS), Steam.
