# 08 — Концовки

> Реализуется в `src/run/endings.ts`.
> Связанные блоки: [02-phi](02-phi.md), [07-run-loop](07-run-loop.md).

Концовка определяется итоговым состоянием системы — балансом Φ, Хаоса, Нейкоса и тем,
пережит ли кризис:

| Концовка | Условие | Смысл |
|---|---|---|
| **Слепое Болото** | жизнь выжила, Φ низкая | существование без сознания |
| **Пророк Без Рук** | прогноз был, табличек не было, система пала | предвидеть — не значит мочь |
| **Тиран Будущего** | кризис пережит, но свобода частей задушена (Нейкос ≈ 0 принудительно) | безопасность ценой живого |
| **Сфайрос / Ложный Абсолют** | Нейкос = 0, полное слияние | единство, убившее различие |
| **Мудрая Грибница** | кризис пережит табличками, баланс сохранён | разум победил будущее подготовкой |
| **Абсолют Через Различие** | высшая Φ при живом Нейкосе и свободе частей | множество стало единым, оставшись многим |

**Минимум для MVP — 4 концовки:** Слепое Болото, Пророк Без Рук, Сфайрос, Мудрая Грибница.
