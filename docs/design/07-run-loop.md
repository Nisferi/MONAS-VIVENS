# 07 — Петля одной партии, биомы и архетипы

> Реализуется в модуле `src/run/`.
> Связанные блоки: [06-tablets](06-tablets.md), [08-endings](08-endings.md).

## Петля партии

```
1. Выбор биома (3) и архетипа (3) → 9 вариантов старта
2. GENESIS    (линза 1): начертай Ме, добейся устойчивых кластеров. Φ растёт
3. МОРФОГЕНЕЗ (линза 2): свяжи узлы в форму. Открывается горизонт прогноза
4. УГРОЗА: прогноз показывает детерминированный кризис через N тиков (виден в тумане)
5. РАЗУМ      (линза 3): высеки Таблички Судеб против угрозы. Расти Φ
6. КРИЗИС НАСТУПАЕТ: таблички срабатывают (или их не было). Система переживает или рушится
7. ФИНАЛ: концовка + Φ-счёт + Глиняная летопись
```

## Биомы (стартовая среда, модифицирует поле)

| Биом | Особенность |
|---|---|
| Глиняное болото | медленный рост, высокая стабильность форм |
| Горячий источник | быстрая энергия, высокий Хаос |
| Кристаллическая пещера | сильная Мнемозина, медленные мутации |

## Архетипы (стартовое Семя, модифицирует правила)

| Архетип | Стиль |
|---|---|
| Искра | энергия, быстрый рост, риск выгорания |
| Глина | форма, устойчивость, медленный старт |
| Эхо | сигналы, ранний доступ к прогнозу |

## Рейтинг

Локальный счёт в MVP; лидерборд Weekly Seed — пост-MVP.

```
Score = Φ_финальное
      + бонус за пережитый кризис
      + бонус за дальность точного прогноза
      + бонус за баланс (Нейкос в живом диапазоне)
      + бонус концовки (Абсолют Через Различие — максимальный)
      − штраф за Хаос
```

Принцип элегантности: меньше Ме-правок и табличек при том же результате — выше счёт
(стиль Zachtronics).

## Глиняная летопись

Финальный экран — короткий текст, собранный из шаблонов по достигнутым вехам партии:
какие формы родились, что предсказал разум, как встретил кризис, чем стал мир.
Летопись + seed = артефакт, которым можно делиться (основа будущего асинхронного
мультиплеера).
