# MONAS VIVENS
### The Fractal Self

Философская artificial-life roguelite-игра: игрок — закон, а не рука. Он начертывает
Ме (правила жизни), растит Филию (связи), хранит щепотку Нейкоса и высекает Таблички
Судеб против детерминированного будущего. Цель — провести мир от одной слепой клетки
до разума, измеряемого величиной Φ.

## Документация

Полный дизайн-канон разбит на модульные блоки: **[docs/design/](docs/design/README.md)**.
Каждый блок (концепция, словарь, Φ, линзы, будущее, таблички, концовки, архитектура,
план MVP, эстетика, риски) — отдельный файл, улучшается независимо.

## Статус

План сборки и прогресс: [docs/design/10-mvp-plan.md](docs/design/10-mvp-plan.md).

- ✅ Шаг 1 — `core` + `ui/canvas`: поле 64×64, чистый `tick()`, живые паттерны.
- ✅ Шаг 2 — `core/rules` + панель Ме: ползунки законов меняют жизнь на лету.
- ⬜ Шаг 3 — `phi` + линза 2: кластеры, узлы, число Φ.

## Архитектура (кратко)

```
src/
  core/      ядро симуляции — чистые функции, без DOM
  phi/       измерение сознания (Φ)        [шаг 3]
  lens/      система линз                  [шаг 3]
  future/    детерминированное будущее     [шаг 4]
  tablets/   Таблички Судеб                [шаг 5]
  run/       петля партии, концовки        [шаг 6]
  ui/        Canvas-рендер и HUD
  platform/  Telegram / PWA / storage      [шаг 7]
```

Главный контракт: `tick(state, rules) → state` — чистая функция. Прогноз будущего —
тот же `tick`, прогнанный вперёд; никакого скрытого RNG после старта партии.
Подробнее: [docs/design/09-architecture.md](docs/design/09-architecture.md).
